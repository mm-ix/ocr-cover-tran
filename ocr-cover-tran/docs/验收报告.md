### 5.6 排除自身（F-14，策略 PASS / 已知偏差）

- 代码调用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`。
- 实测：在**分层窗口**上，该 API 对 GDI/BitBlt 截图不生效（`tests/exclude.ps1` 的测试截图仍能看到暗化层与译文）。
- 实际保护策略：**每次新截图前 `CloseTransient()` 关闭上一轮覆盖层**，并在截图前隐藏框选窗口，因此自身覆盖层不会被本工具二次识别；100 次连续触发验证通过。
- 结论：F-14 的实际意图（避免自身干扰识别）满足；WDA 保留为尽力而为，报告此 Windows 限制。

## 7. 偏差与后续

1. **F-14 WDA 限制**：分层窗口在 GDI 截图中不能被 WDA 排除；已用“截图前关闭旧覆盖层”保证不自扰。如必须对第三方截图隐藏覆盖层，可评估非分层渲染或 DWM cloak，但会影响逐像素透明度。
2. **英文 OCR 语言包**：本机未安装 en-US；程序已做拆词合并、字符级混淆修正、代码保护误判修正和翻译提示纠错（`L°CENSE`→`LICENSE`、`HeIIo`→`Hello`、`kerne132`→`kernel32` 等），但生僻词/代码词的字符级误识别仍需安装英语语言包解决。设置页提供一键「安装英文 OCR…」（UAC + 联网），安装后选择 en-US / auto 即可。P2 可挂 PaddleOCR。
3. **混合 DPI**：两屏均 150%，混合缩放未实机验证；代码使用 PerMonitorV2 + 物理像素。
4. **托盘右键**：任务栏自动隐藏，未自动化点击；建议按手动清单确认。
5. **剪贴板**：划词翻译只恢复文本剪贴板，图片等非文本格式不保留；使用 Win32 API 超时，避免卡死。
6. **翻译延迟**：由用户配置的接口决定；程序端一次批量请求，不额外串行。
7. **鼠标交互取舍**：为支持译文鼠标选中复制，译文文字区域会接收鼠标（拖选 / 右键菜单）；空白区域仍穿透。文字区域的点击不再传给下方应用，这是文本选择功能所需的行为。
