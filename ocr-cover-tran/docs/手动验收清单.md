# ShotTrans 手动验收清单

> 用于无法解锁自动化桌面时人工逐项确认。绿色版：`publish/green/ShotTrans.exe`。
> 建议测试页：`test-artifacts/test-page.html`（Chrome 打开），英文文本位置稳定。

## 0. 首次启动

- [ ] 双击 `ShotTrans.exe`，托盘出现「译」图标，首次启动打开设置。
- [ ] 填写 Base URL / API Key / 模型；点「测试连接」显示成功。
- [ ] 保存后托盘菜单显示两个热键。

## 1. 框选（F-01/F-02）

- [ ] 设置 → 常规 →「OCR 语言包」：点击「安装英文 OCR…」，同意 UAC 并联网安装；完成后「刷新语言」并选择 `en-US`（或保持 auto，程序会优先 en-US）。
- [ ] 在 Chrome 测试页按 `Ctrl+Alt+X`：全屏变暗，顶部提示「拖拽选择翻译区域 · Esc / 右键取消」。
- [ ] 拖拽时显示 `宽 × 高`，数值随选区变化。
- [ ] 拖拽中按 Esc：取消，无残留窗口；再次按热键可立即重开。
- [ ] 右键取消同样有效。

## 2. 截图与 OCR（F-03/F-04）

- [ ] 框选测试页文字区域，松手后 2 秒内出现译文（或先出现原文占位再变译文）。
- [ ] 125% / 150% 缩放下重复：框选范围与截图范围一致，译文覆盖位置正确。
- [ ] 框选纯空白区域：提示「没识别到文字」，约 1 秒后消失。

## 3. 原位覆盖与样式（F-05/F-06/F-07）

- [ ] 译文出现在每个原文文字块的位置，不溢出、不压住相邻块。
- [ ] 窄框内长译文保持可读字号并向下扩展卡片，块间不重叠；空间确实不足时才缩小/省略。
- [ ] 浅色背景显示黑字；深色背景（测试页深色块）显示白字。
- [ ] 顶部状态条显示「已翻译 N 块 · X.Xs  Space 看原文 / Esc 关闭」，约 3 秒淡出。

## 4. 对比与复制（F-10/F-11）

- [ ] 覆盖层状态条位于选区外（上方/下方），不遮挡任何译文；约 3 秒淡出。
- [ ] 按住 `Space`：显示原文；松开恢复译文，不重新请求翻译。
- [ ] 用鼠标拖选译文文字（应像普通文本一样出现选中高亮）；右键弹出菜单 →「复制」，粘贴结果应为选中的文字。
- [ ] 没有选中文字时按 `Ctrl+C`：提示「已复制全部译文」；粘贴到记事本为按阅读顺序拼接的译文；有选中时只复制选中部分。
- [ ] 右键菜单还提供「复制全部译文」「取消选择」。

## 5. 点击穿透与关闭（F-08/F-09）

- [ ] 覆盖层显示时，点击**译文文字以外**的空白区域，可正常操作下方 Chrome 页面/按钮。
- [ ] 译文文字区域用于鼠标选中，点击不会传给下方窗口（文本选择功能所需）。
- [ ] 点击译文块以外的区域：覆盖层关闭，点击事件传递给下方窗口。
- [ ] 右键任意位置：覆盖层关闭。
- [ ] Esc：关闭。
- [ ] 关闭后立即再次按热键：正常工作，无残留窗口（任务栏/Alt+Tab 中无覆盖层）。

## 6. 欠配置/失败重试（F-19）

- [ ] 故意把 API Key 改错，框选翻译：覆盖层显示原文 + 顶部红条「翻译失败：…  R 重试 / Esc 关闭」。
- [ ] 打开设置改回正确 Key（覆盖层可暂时留在后面），关闭设置后按 `R`：复用原截图重试成功。
- [ ] 全程未重新框选。

## 7. 术语保护（F-16）

- [ ] 测试页包含 `GetProcAddress`、`kernel32.dll`、`10.0.19041`、Windows 路径：译文中这些内容保持原样。
- [ ] 在设置 → 术语表添加 `GetProcAddress=获取函数地址`，保存后重试：对应位置显示「获取函数地址」。
- [ ] 关闭「自动保护代码标识符」开关后再试：标识符可能被翻译（开关生效）。

## 8. 多屏与 DPI（F-12/F-13）

- [ ] 副屏框选：坐标正确，译文落在副屏原位置。
- [ ] 从主屏拖到副屏：框选/截图/覆盖均正常。
- [ ] 每屏缩放不同（如 100% + 150%）：框选范围与截图一致，覆盖层文字清晰。
- [ ] RDP 会话内重复上述 1~5 项。

## 9. 划词翻译（F-23）

- [ ] 在 Chrome 选中一段英文，按 `Ctrl+Alt+Z`：弹出译文卡片；标题「划词翻译」。
- [ ] 卡片里的译文可用鼠标拖选；选中后右键 →「复制」/「复制全部译文」。
- [ ] 卡片显示约 15 秒后自动关闭；Esc / 点击外部也可关闭。
- [ ] 按 `Ctrl+C`：译文复制到剪贴板。
- [ ] 验证原剪贴板内容在取词后被恢复（先复制一段已知文本，再划词，然后粘贴）。
- [ ] 选中中文后按热键：显示「原文已是中文」卡片，不请求翻译。
- [ ] 未选中文字时按热键：提示「未选中文字」。

## 10. 历史记录（F-18，默认关）

- [ ] 默认配置中 `HistoryEnabled=false`，翻译后 `history.db` 不新增记录。
- [ ] 设置中开启历史 → 翻译一次 → 托盘「历史记录」：出现缩略图 + 时间 + 原文 + 译文。
- [ ] 复制原文/译文按钮可用；删除单条、清空全部有效。
- [ ] 连续记录超过 200 条后只保留最近 200 条。
- [ ] 关闭历史开关后新翻译不再记录，旧记录仍可查看。

## 11. 设置与托盘（F-15/F-17）

- [ ] 设置页可改：截图/划词热键、OCR 语言、字号上下限、背景不透明度、状态条淡出、对齐、超时、术语、历史、开机自启、调试日志。
- [ ] 调试日志默认关闭：关闭时不创建/不写入 `logs` 目录；开启后 `logs\shotrans.log` 正常写入。
- [ ] 修改热键后立即生效；旧热键失效；两个热键相同/无效时保存会报错。
- [ ] 托盘菜单：截图翻译 / 划词翻译 / 历史记录 / 设置 / 开机自启 / 退出 均可用。
- [ ] 开机自启勾选后，`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ShotTrans.lnk` 存在；取消后删除。
- [ ] 退出后热键注销，托盘图标消失；再次启动正常（单实例）。

## 12. 稳定性与兼容性（非功能）

- [ ] 连续触发 100 次（每次关闭后立刻再触发）：无崩溃、无残留窗口，任务管理器内存无明显持续增长。
- [ ] 翻译 20 行文字：记录端到端耗时（目标 ≤2.5s，受接口影响）。
- [ ] 独占全屏游戏：截图失败时提示改用无边框；无边框全屏可正常翻译。
- [ ] 绿色目录 ≤40MB；目标机无需安装 .NET；无需管理员。
- [ ] 隐私：抓包或代码检查确认只发送文字，不上传截图；日志不含原文/译文/Key。
