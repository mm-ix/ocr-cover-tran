## 一、如何运行

### 1.1 启动

1. 将整个文件夹放到任意位置（例如 `D:\Tools\ShotTrans`），**无需安装**。
2. 双击 `ShotTrans.exe`。
   - 不需要管理员权限。
   - 如果 Windows SmartScreen 提示「已保护你的电脑」，点击 **更多信息 → 仍要运行**。
3. 启动后程序常驻系统托盘（任务栏右下角的「译」图标）。

### 1.2 首次配置翻译接口

第一次运行会自动打开「设置 → 翻译接口」：

| 项目 | 说明 | 示例 |
|---|---|---|
| Base URL | OpenAI 兼容接口地址 | `https://host/v1` 或完整地址 `https://host/v1/chat/completions` |
| API Key | 你的接口 Key | `sk-...` |
| 模型 | 接口支持的模型名 | `hy-mt2-lite` |

填写后点击 **测试连接**；成功后点击 **保存**。

> 截图与 OCR 结果只在本机处理，只有识别出的**文字**会发送到你配置的接口。

## 二、截图翻译（默认 `Ctrl+Alt+X`）

### 2.1 基本流程

1. 在任意窗口按 `Ctrl+Alt+X`，屏幕变暗。
2. 拖拽框选要翻译的区域，松手等待译文。
3. 译文按原文文字块的位置覆盖显示。

### 2.2 快捷键

| 操作 | 效果 |
|---|---|
| 鼠标拖动译文文字 | 像正常文本一样选中译文（字符级） |
| 选中后右键 | 弹出菜单 → 复制选中文字 / 复制全部译文 |
| 按住 `Space` | 临时查看原文，松开恢复译文 |
| `Ctrl+C` | 复制选中的译文；没有选中时复制全部译文 |
| `R` | 翻译失败时重试（复用原截图，不需要重新框选） |
| `Esc` / 右键 / 点击译文块外部 | 关闭覆盖层 |
| 框选时按 `Esc` 或右键 | 取消框选 |

> 覆盖层的**空白区域**仍然鼠标穿透，可以继续操作下方窗口；**译文文字区域**可以拖选和右键复制。

## 三、划词翻译（默认 `Ctrl+Alt+Z`）

1. 先选中一段文字。
2. 按 `Ctrl+Alt+Z`，在弹出的卡片中查看译文。
3. 卡片里的译文可以像普通文本一样用鼠标拖选；选中后**右键 → 复制**。
4. `Ctrl+C` 也可复制（选中时复制选中部分，否则复制全部译文）；`Esc` 或点击卡片外部关闭。
5. 取词后会恢复你原来的剪贴板文本。

## 四、设置、历史与托盘

### 4.1 托盘菜单

| 菜单项 | 功能 |
|---|---|
| 截图翻译 | 立即进入框选 |
| 划词翻译 | 翻译当前选中文字 |
| 历史记录 | 查看最近 200 条记录 |
| 设置 | 热键、OCR、接口、术语表等 |
| 开机自启 | 启动文件夹快捷方式（不写注册表） |
| 退出 | 退出程序 |

> 状态条（「已翻译 N 块…」）会自动放在选区**上方或下方**，不遮挡译文；3 秒后淡出。

### 4.2 设置页

- **常规**：截图/划词热键、OCR 语言、OCR 语言包、字号、背景不透明度、超时、对齐、历史记录、开机自启、**调试日志（默认关闭）**。
- **翻译接口**：Base URL、API Key、模型、温度、超时，可测试连接。
- **术语表**：每行 `原文=译文`，例如 `GetProcAddress=获取函数地址`。
- **关于**：版本、数据目录、已知限制。

> 调试日志默认关闭，关闭时不会创建或写入 `logs` 目录；需要排查问题时再到「常规」中开启。

### 4.3 历史记录

- **默认关闭**。
- 在设置中开启后，保存最近 200 条：缩略图 + 原文 + 译文，存本地 SQLite。
- 可复制原文/译文、删除单条或清空全部。

## 五、安装英文 OCR 语言包（强烈推荐）

本工具使用 Windows 自带 OCR。如果本机没有英文 OCR 语言包，英文识别会不准确
（例如 `kerne132`、`HeIIo`、`L°CENSE`）。安装英文 OCR 后，准确率会明显提升。

### 方式① 图形界面（最稳，推荐）

1. 打开：**设置 → 时间和语言 → 语言 → 添加语言**。
2. 搜索 `English`，选择「**英语(美国)**」，点击**下一步**。
3. 只勾选「**安装语言包**」（OCR 就在这个包里）。
4. **取消勾选**「**设为我的显示语言**」。
   > 重要：否则你的系统界面会变成英文。
5. 点击**安装**，等待完成（约 2 MB，需要联网）。

### 方式② 管理员 PowerShell（约 2 MB）

1. 以管理员身份打开 PowerShell。
2. 执行：

   ```powershell
   Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
   ```

3. 等待安装完成。

### 安装后启用

1. 打开 ShotTrans **设置 → 常规**。
2. 点击 **OCR 语言包 → 刷新语言**。
3. 在「OCR 语言」中选择 `en-US`；或保持「自动」，程序会优先使用 `en-US`。
4. 如果仍没有 `en-US`：重启 ShotTrans 或重启 Windows 后再试。

> 设置页里的「**安装英文 OCR…**」按钮会自动以管理员权限执行方式②；UAC 弹窗点「是」即可。

## 六、常见问题

### Q1：按热键没有反应？

热键可能被其他软件占用。打开 **设置 → 常规**，修改截图/划词热键。

### Q2：翻译失败怎么办？

覆盖层顶部会显示红色错误原因。检查 Base URL / API Key / 模型；修正后按 `R` 重试。

### Q3：英文识别差（`kerne132`、`HeIIo`、`L°CENSE`）？

安装英文 OCR 语言包（见第五章），并在设置中选择 `en-US`。
程序已内置拆词合并和常见字符纠错，但生僻词仍需要英文 OCR 模型。

### Q4：截图全黑 / 提示无法截取？

独占全屏（Exclusive Fullscreen）游戏无法通过 GDI 截取。请把游戏改为**无边框窗口 / Borderless** 模式。

### Q5：历史记录没有内容？

历史记录默认关闭。请在 **设置 → 常规** 中开启「启用本地历史记录」。

### Q6：杀毒软件或 SmartScreen 提示？

绿色版是自包含单文件程序，可能被误报。可选择信任，或从源码自行构建。

### Q7：语言包安装失败？

- 确认使用的是**管理员 PowerShell**；
- 确认电脑能联网（部分 LTSC / 企业环境需要能访问 Windows Update）；
- 也可以使用第五章的方式①图形界面安装。
